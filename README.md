# Headie — Portfolio

Cinematic personal portfolio for **Headie** (`@iamheadie`) — AI video creator and visual storyteller.

- Site: https://headie-portfolio.vercel.app
- Repo: https://github.com/iamHeadie/headie-portfolio

## Local

```bash
npm install
npm run dev
```

## Add videos

Put MP4s in `public/videos/` and posters in `public/images/`.
Paths live in `src/lib/projects.ts`. Identity lives in `src/lib/site.ts`.
